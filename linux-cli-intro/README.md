# NYITSec officer notes — Optional Linux & CLI Quick Start

This module is a **reading-only introduction** placed before CTF Fundamentals. It intentionally has **no challenges**, which means there are no platform flags or solve points for completing it.

All three lessons are pwn.college Markdown resources declared in `module.yml`. This follows pwn.college's supported `type: markdown` resource format.

## What to expect on the platform

- **Lecture content:** Three expandable Markdown resources on the module page.
- **No workspace launched by the lecture:** Students can launch the subsequent CTF Fundamentals challenge to practice using the terminal.
- **No score:** `challenges: []`. Visiting or reading the resource does not result in a tracked CTF solve.
- **AI guidance:** Emphasizes command explanations, debugging, and guided hints over copied solutions, along with privacy and event-rule safeguards.

For the future in-person workshop, you can add a recorded YouTube lecture or slides using `type: lecture` with `video:` or `slides:` in this module's resources, without making it a graded challenge.

Validate after deployment: the module appears **before** CTF Fundamentals; the three resources expand; no "Start challenge" or flag submission is required for this module; and the existing First Incident challenge still works.
