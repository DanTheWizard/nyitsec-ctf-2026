# Linux & CLI Quick Start (Optional)

**Start here if you are new to Linux or command-line tools.** This is a short, self-paced, **ungraded** reading mini-lecture to support our upcoming NYITSec Linux/CLI workshop.

Learn how to navigate Linux, read and search files, and ask AI for explanations or hints while still solving challenges yourself.

**Need help while solving?** pwn.college has [SENSAI](https://pwn.college/sensai), an optional AI assistant that can use context from your active challenge and workspace. Start a challenge and select **Help** in the top navigation bar to ask for hints, explanations, or troubleshooting. ChatGPT and other AI tools are also welcome in this dojo.

**No challenge, no flag, no points, and no required completion.** You can skip this module and begin CTF Fundamentals at any time.

Open the three learning resources below in order. When you are ready, move on to **CTF Fundamentals → First Incident: SSH Log Investigation**.
