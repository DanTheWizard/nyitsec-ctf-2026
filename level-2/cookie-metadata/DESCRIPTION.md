# More Than a Cookie Recipe

An investigator found a file called `document.txt`. Opening it normally shows a chocolate chip cookie recipe, but the team suspects there may be **additional information hidden in the file**.

**Goal:** Recover the hidden case code.

Your terminal starts in `/nyitsec-ctf`.

```bash
ls
cat document.txt
file document.txt
```

**Hint:** What you see on the screen is not always everything stored in a file. Explore other ways to inspect the file's contents and recover readable information.

When you find the case code, run `nyitsec-answer` and submit the flag you receive.

**Temporary workspace:** Files you create in `/nyitsec-ctf` disappear when the challenge restarts. Save important work to `~/`.
