# ISC dig and bundled library provenance

This Level 3 challenge ships a prebuilt **genuine ISC dig** executable from
Ubuntu 24.04's `bind9-dnsutils` package, plus its non-glibc runtime
dependencies. The archive is generated by the authoring-only script
`tools/build_dns_dig_runtime.py` on an Ubuntu 24.04 GitHub Actions runner.

BIND 9 is free software distributed under the Mozilla Public License 2.0.
Other third-party bundled libraries may carry different licenses.
The exact included library paths are listed in the companion
`level-3/dns-treasure-hunt/.dig-runtime-packages.txt` file.

Source and licenses:
- ISC BIND 9: https://gitlab.isc.org/isc-projects/bind9
- Ubuntu BIND 9 source: https://launchpad.net/ubuntu/+source/bind9
- Mozilla Public License 2.0: https://www.mozilla.org/en-US/MPL/2.0/
- Ubuntu packages: https://packages.ubuntu.com/

Rebuilders and redistributors must comply with the licenses of **all** bundled
libraries, and retain the appropriate source and license notices.

The `/challenge/bin/dig` wrapper extracts this archive into a throwaway
directory under `/tmp` and runs it as the ordinary `hacker` user.
It does not use elevated privileges, reach the network, or install packages
when students launch the challenge.
