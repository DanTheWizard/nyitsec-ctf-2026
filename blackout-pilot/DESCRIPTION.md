# Operation Blackout - Progress Lock Pilot

**Purpose:** Test whether a participant must submit the previous stage's unique pwn.college flag before starting the next stage.

1. **Signal Intercept:** Available immediately; decode Base64.
2. **Incident Investigation:** Locked until Stage 1 is solved; investigate a synthetic SSH log.
3. **Restore Communications:** Locked until Stage 2 is solved; decode ROT13.

After each `nyitsec-answer` success, submit the **unique flag** to pwn.college. Generating the flag alone does not count as a recorded solve. Refresh the module page to observe unlocking.

All data are synthetic and confined to the authorized training environment. This is **not a scored Operation Blackout competition round**.
